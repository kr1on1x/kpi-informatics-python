# Лабораторна робота №3

**Тема:** Рядки, списки та матриці
**Варіант:** 8

## Частина А - Рядки

Стискання послідовностей однакових символів.

```text
aaabbc → a3b2c1
```

Реалізував функцію `compress_string()`.

## Частина Б - Матриці

Виведення всіх елементів **над головною діагоналлю** матриці.

Для елемента використовується умова:

```text
j > i
```

Реалізовано функцію `above_main_diagonal()`.

## Запуск

```bash
python3 main.py
```
